# Real-Time-Security-Operations-Center-SOC-Project

## Overview

This repository contains six cybersecurity projects completed as part of my cybersecurity internship. These projects cover threat analysis, Red Team and Blue Team operations, SIEM detection engineering, incident response, digital forensics, and security monitoring.

Each project includes a report documenting its objectives, methodology, tools, findings, and relevant security concepts.

## Projects

### 1. HawkEye Lab – Red Team, Blue Team & Purple Team Analysis

**Objective:** Analyze the CyberDefenders HawkEye lab from offensive and defensive security perspectives.

**Reports included:**
- Red Team Report – Attack techniques and attacker methodology.
- Blue Team Report – Threat detection, investigation, and defensive measures.
- Purple Team Report – Combined attack and defense findings with handover recommendations.

**Platform:** CyberDefenders

### 2. SIEM Correlation Rules for Attack Detection

**Objective:** Develop and document custom SIEM correlation rules for detecting common attack techniques.

**Detection use cases:**
- Credential stuffing
- DNS tunnelling
- PowerShell exploitation

**Platform:** ELK Stack

### 3. Multi-Stage Advanced Persistent Threat (APT) Simulation and Response

**Objective:** Study a multi-stage APT attack and document the techniques used for attack simulation, detection, investigation, threat intelligence, and mitigation.

**Key areas covered:**
- Initial access, persistence, and privilege escalation
- Lateral movement and data exfiltration
- Security alert investigation and IoC analysis
- Incident timeline reconstruction
- Threat intelligence and detection rules
- Incident response and remediation recommendations

**Tools and platforms covered:** Wazuh, Security Onion, Kibana, TheHive, Cortex, MISP, YARA, and Sigma.

### 4. HawkEye Lab – CyberDefenders Investigation

**Objective:** Solve and document the HawkEye Blue Team CTF challenge, recording the investigation workflow, tools, and findings.

**Platform:** CyberDefenders

**Deliverable:** Detailed lab investigation report and supporting documentation.

### 5. Brutus Lab – SSH Brute-Force Investigation

**Objective:** Investigate an SSH brute-force attack using authentication logs and identify suspicious login activity.

**Key areas covered:**
- SSH authentication log analysis
- Failed and successful login investigation
- Source IP and attacker activity analysis
- Attack timeline reconstruction
- Detection and mitigation recommendations

**Platform:** Hack The Box

### 6. Custom SIEM Dashboard for Security Monitoring

**Objective:** Design and document a custom SIEM dashboard for monitoring critical security events.

**Monitoring use cases:**
- Brute-force attacks
- Privilege escalation
- Suspicious activity and potential data exfiltration

**Platform:** ELK Stack / Kibana

**Deliverable:** SIEM dashboard project report and related documentation.
